pkg/ 以分层方式组织 ResolveAgent 的共享库：最底层是 shared_utils（config/errors/event/logger/retry/health/version），被所有上层模块直接依赖；其上是 registry（内存型 CRUD 注册表）与 store_backends（PostgreSQL/Redis/内存持久化抽象），二者通过 store/store.go 定义的接口解耦，registry 通过 store 访问数据；server 作为 HTTP/gRPC 入口聚合各域 handler，并组合使用 registry、store、telemetry、gateway、feedback 等能力对外暴露 API；gateway 将内部服务通过 Higress 路由同步暴露；feedback 在 agent 执行链路中采集信号并通过 event/nats 或指标导出形成闭环；telemetry 通过中间件为 server 提供日志、指标与链路追踪的统一注入。各子模块之间通过包级接口与共享类型（如 config.Config、errors.Code、event.EventBus）通信，避免直接耦合。
