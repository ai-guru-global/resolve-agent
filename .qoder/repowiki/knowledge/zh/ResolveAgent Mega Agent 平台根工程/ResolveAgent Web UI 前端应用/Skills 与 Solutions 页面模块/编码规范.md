- 页面通过 `PageHeader` 统一渲染标题、描述与面包屑，并在 loading/error 分支中返回对应的骨架或错误 UI。
- 列表页使用本地 `useState` 管理筛选/搜索关键词/删除目标等交互状态，并在 finally 块中重置 loading。
- 对后端枚举（如 `skill_type`、`severity`、`step_type`）采用常量映射表（Record）将英文值转换为中文标签与样式变体。
- Skills 列表与详情页共用 `skillIcons`、`skillDisplayNames`、`skillAgentRefs` 等静态映射表来展示名称、图标与引用 Agent。
- Solutions 详情页将四要素（问题现象、关键信息、排查步骤、解决方案）抽取为独立的 `SolutionSection` 子组件重复渲染。
- 所有用户反馈通过 `sonner` 的 `toast.success` / `toast.error` 提示操作结果，保持统一的交互反馈方式。
