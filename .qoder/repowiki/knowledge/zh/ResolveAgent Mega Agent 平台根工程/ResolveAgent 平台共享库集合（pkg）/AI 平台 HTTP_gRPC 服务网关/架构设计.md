server.go 中的 Server 结构体持有所有领域 registry（Agent/Skill/Workflow/RAG/Hook/Memory/Solution/CallGraph/Traffic）及 RuntimeClient，在 New() 中根据 config.Store.Backend 选择 postgres 或 in-memory 实现注入；router.go 的 registerHTTPRoutes 将 /api/v1/* 路径集中映射到各 handler 文件中的 handleXxx 方法；middleware/ 提供 auth、logging、telemetry、tracing 横切能力；gRPC server 仅注册 health 与 reflection，业务通过 HTTP REST 暴露。每个 handler 文件对应一个领域，通过注入的 registry 访问持久化层，形成「路由 → 处理器 → 注册表 → 存储」的统一调用链。
