根目录通过 `go.mod`（`github.com/ai-guru-global/resolve-agent`）聚合所有 Go 子模块（`internal/`、`pkg/`、`cmd/`），并以 `Makefile` 作为跨语言构建入口：`build-go` 编译 `cmd/resolveagent-server` 与 CLI，`build-python` 在 `python/` 下执行 `uv sync`，`build-web` 在 `web/` 下执行 `pnpm build`；测试、lint、Docker 镜像、Helm 发布等目标均按相同模式串联各子组件。API 契约集中在 `api/proto`，由 `make proto` 调用 `hack/generate-proto.sh` 生成 Go/Python 代码供 `internal_go`、`python_runtime`、`test_suite` 共同消费。运行时依赖（PostgreSQL、Redis、NATS、Prometheus）通过 `deploy/docker-compose/` 统一拉起，`deploy/helm/` 与 `deploy/kustomize/` 提供 K8s 部署视图。文档站点 `docs-site/`（Docusaurus）与源码同步由 `python/resolveagent-docsync` 驱动，形成“源码 → API 定义 → 代码生成 → 服务实现 → 文档”的闭环。
