模块以 `tree.py` 中的 `FaultTree`/`FTAEvent`/`FTAGate` 数据模型为核心，定义事件类型与门类型枚举；`evaluator.py` 提供 `NodeEvaluator`，通过解析 `event.evaluator` 字符串（`skill:`/`rag:`/`llm:`/`static:`/`context:`）将基本事件分派到对应异步求值器，并内置基于 `(event_id, context)` 的缓存；`engine.py` 的 `FTAEngine.execute` 作为顶层编排：先并发评估所有基本事件，再按 `FaultTree.get_gates_bottom_up()`（Kahn 拓扑排序）自底向上求上门，并通过可选 `fta_client.create_result` 持久化结果；`parallel_evaluator.py` 继承 `NodeEvaluator` 实现 `ParallelFTAEvaluator`，用 Kahn 算法构建评估层级并以 `asyncio.gather` 并行执行每层节点，辅以 `_LRUCache` 和概率阈值剪枝；`gates.py` 提供纯函数形式的门逻辑，`cut_sets.py` 实现 MOCUS 算法计算最小割集、解释与概率排名；`serializer.py` 负责 YAML 双向序列化；`workflow.py` 定义通用 DAG 工作流结构（节点/边/可达性校验）；`feedback_loop.py` 与 `regression_validator.py` 构成“执行→度量→基线对比→改进建议”的闭环，前者维护历史窗口与基线，后者在变更部署前对时长/成功率/覆盖率/新错误模式做回归检查。依赖方向单向：engine → evaluator → (skills/llm/rag)，cut_sets/serializer/workflow/feedback_loop/regression_validator 仅依赖 tree 或彼此之间低耦合。
