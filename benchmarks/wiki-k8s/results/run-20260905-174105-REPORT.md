## 基模典型事实错误(judge 摘录)

- 未明确提到Deployment的"声明式"特性和"期望状态"概念
- 未提及 EndpointSlice（只提到 Endpoints）
- 未说明 EndpointSlice 最大 100 个 endpoints 的限制
- 候选答案提到 Endpoint 对象，但参考答案要求 EndpointSlice 这一具体对象名称
- 使用'Endpoint'而非'EndpointSlice'：Kubernetes当前推荐使用EndpointSlice而非Endpoint来记录后端Pod信息
- 缺少'100个'这个数字：EndpointSlice默认每个最多包含100个endpoints，超出时自动分片
- 命令行参数的描述不准确：候选答案说'通过 ${VAR_NAME} 引用环境变量'，但正确方式是在 Pod 的 command 字段中直接引用 ConfigMap 值作为命令行参数，而非先设置为环境变量
- 候选答案未明确提到通过命令行参数引用 ConfigMap 值（如 command: ["--config", "$(CONFIG_PATH)"]）的方式
- 未提及 IngressClass 资源及其作用
- 未提及 spec.ingressClassName 字段用于指定控制器
