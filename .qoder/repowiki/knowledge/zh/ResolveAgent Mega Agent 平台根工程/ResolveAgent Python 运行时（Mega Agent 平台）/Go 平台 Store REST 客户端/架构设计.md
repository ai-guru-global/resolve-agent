模块以 `base_client.BaseStoreClient` 为统一基类，集中管理 `httpx.AsyncClient` 的连接生命周期（`connect`/`close`）以及 GET/POST/PUT/DELETE 四种 HTTP 方法的通用重试与错误处理；每个领域资源（Hook、Memory、Solution、CodeAnalysis、FTADocument、RAGDocument、CallGraph、TrafficCapture、TrafficGraph、Skill）各自实现一个继承自该基类的 Client 类，暴露对应资源的 CRUD 方法并映射到 `/api/v1/...` 路径。`__init__.py` 仅导出对外可见的六个核心 Client（Hook/RAG/FTA/CodeAnalysis/Memory/Solution），其余 Client 作为内部扩展未公开。数据模型使用 Python dataclass 将 JSON 响应反序列化为强类型对象，使上层调用方无需直接操作原始字典。依赖方向单向：所有具体 Client → BaseStoreClient → httpx，不反向依赖上层业务逻辑。
