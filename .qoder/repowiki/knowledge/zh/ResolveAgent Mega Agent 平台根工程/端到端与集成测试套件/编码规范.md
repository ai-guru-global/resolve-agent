- 每个测试文件以 `package e2e` 或 `package integration` 组织，并通过 `t.Run` 将单一测试拆分为多个步骤子用例（如 CreateAgent、GetAgent、ExecuteAgent）。
- 对外部服务的访问统一封装为 `skipIfNoServer` 辅助函数，先探测 `/healthz` 再决定是否跳过，避免在无服务器环境中断 CI。
- HTTP 响应体使用 `json.NewDecoder` 解码到匿名 struct 或 `map[string]interface{}`，并对状态码进行断言后再解析 body。
- 长耗时或需要外部依赖的测试在开头检查 `testing.Short()` 并调用 `t.Skip`，以便短跑模式下快速跳过。
- 测试固定数据以独立 YAML 文件存放在 `test/fixtures/{agents,skills,workflows}/` 下，便于在不同测试间复用。
- 集成测试通过 `//go:build integration` 构建标签隔离，默认不参与常规 `go test`，需显式传入 `-tags=integration` 触发。
