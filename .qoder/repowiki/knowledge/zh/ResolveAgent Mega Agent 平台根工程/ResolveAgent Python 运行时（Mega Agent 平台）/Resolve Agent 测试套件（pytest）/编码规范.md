- 每个被测类对应一个 `TestXxx` 类，测试方法以 `test_` 前缀命名并按功能分组放置于类中。
- 异步测试统一使用 `@pytest.mark.asyncio` 装饰器，并通过 `await` 调用被测异步 API。
- 测试数据通过 `@pytest.fixture` 在类或模块级提供，如 `pool`、`analyzer`、`strategy`、`manager` 等，避免在每个测试中重复构造。
- 共享的复杂对象（如 FaultTree）通过根级 `conftest.py` 中的 `sample_fault_tree` fixture 注入，YAML 样例存放在 `fixtures/` 目录。
- 对外部依赖（如网络、LLM、文件系统）通过 `unittest.mock.MagicMock` 进行打桩，确保测试可确定性执行。
