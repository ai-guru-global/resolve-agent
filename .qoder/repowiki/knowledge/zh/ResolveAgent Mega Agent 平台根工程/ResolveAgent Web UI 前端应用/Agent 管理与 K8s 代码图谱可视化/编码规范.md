- 数据获取统一通过 `useQuery({ queryKey: [...], queryFn })` 封装在 `hooks/useAgents.ts` 中，页面只消费 hook 返回的 data/isLoading 状态。
- mutation 操作在 useAgents 中以 useMutation 实现，并在 onSuccess 中通过 queryClient.invalidateQueries 精确失效对应的 agents 列表或单条缓存。
- 页面内枚举值（如 agent type、status、hookType、sandbox、context_strategy）均以本地 `Record<string, string>` 映射表进行中文标签转换，避免硬编码字符串散落。
- Agent 详情页采用 Tabs + Card 的分块布局，每个业务维度（Harness、Status、History、Memory、Analytics 等）独立为一个 TabContent。
- K8s 可视化组件将布局计算（computeSequentialLayout / computeEventDrivenLayout）与 ReactFlow 渲染解耦，通过 useMemo 缓存 layout，再在 useEffect 中同步 nodes/edges。
- 组件间交互通过 props 回调（如 onNodeClick）向上冒泡事件，保持 ChainFlowViewer 无状态且可复用。
