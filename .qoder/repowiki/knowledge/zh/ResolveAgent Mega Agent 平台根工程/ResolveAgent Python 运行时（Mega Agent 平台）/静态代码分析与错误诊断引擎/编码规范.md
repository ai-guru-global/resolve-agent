- 数据模型统一使用 `dataclass` + `field(default_factory=list/dict)` 定义不可变结构体（如 `FunctionDef`、`CallSite`、`ParsedError`、`SolutionDocument`）。
- 多语言扩展点通过字典分派实现：`ASTParser._parse_generic`、`ErrorParser._parse_by_language`、`ParserFactory._initialize` 均以语言标识符映射到具体处理逻辑或类名。
- 对外 API 采用“可注入依赖 + None 回退”模式：`StaticAnalysisEngine`、`SolutionGenerator`、`CallGraphBuilder` 均接受可选的外部客户端并在缺失时降级为本地处理。
- 长耗时分析流程通过 `async def analyze()` 异步迭代器产生带 `type`/`data` 键的 SSE 兼容事件，每个阶段以 `phase: started/error` 状态上报。
- 异常处理遵循“捕获-记录-继续”策略：各阶段 `try/except` 仅 `logger.exception` 后 yield 错误事件，不中断整个分析流水线。
- 文件收集与过滤统一排除隐藏目录及常见非源码目录（`.`, `node_modules`, `vendor`, `__pycache__`, `venv`, `.venv`），并使用 `Path.rglob` 递归扫描。
