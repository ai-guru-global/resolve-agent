- 每个页面目录仅暴露一个 index.tsx 并默认导出单个函数式组件作为路由页面，保持一目录一页的扁平结构。
- 页面统一通过 @/components/PageHeader 渲染标题与副标题，并使用 react-router-dom 的 Link 或 useNavigate 进行导航。
- 状态与数据获取集中在 @/hooks 下的专用 hook（如 useDashboard、useSettings），页面组件只消费 { data, isLoading } 并配合 Skeleton 做加载态占位。
- 业务枚举（agentType、routeType、severity、connectionStatus 等）以 Record<string, ...> 映射表形式在文件顶部集中定义，再用于样式与文案渲染。
- 样式统一采用 Tailwind 原子类，颜色通过 hsl(var(--...)) 主题变量与 cn() 工具组合，避免硬编码色值。
- 静态说明类页面（Selector、FTAEngine、TicketSummary、AgentScopeHigress、SelectorAdapters）采用「常量数组 + map 渲染」的数据驱动表格/卡片模式，将领域知识以声明式数据结构组织。
