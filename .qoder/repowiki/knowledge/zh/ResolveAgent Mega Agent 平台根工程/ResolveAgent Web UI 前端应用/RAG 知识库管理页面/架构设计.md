模块由两个 React 页面组件和一个自定义 Hook 组成：`Collections.tsx` 作为 RAG 入口页，展示 RAG 六阶段管道介绍卡片与集合网格；`Documents.tsx` 通过 `react-router-dom` 的 `useSearchParams` 读取 `collection` 查询参数，按集合过滤并渲染文档表格。数据层统一集中在 `hooks/useRAG.ts`，基于 `@tanstack/react-query` 封装 `useCollections`、`useCollection`、`useDocuments` 三个查询 Hook，queryKey 以 `['rag', ...]` 命名空间隔离缓存，并通过 `api.listCollectionDetails` / `getCollection` / `listDocuments` 访问后端。页面仅负责 UI 呈现（使用 `PageHeader`、`EmptyState`、`DataTable`、`Card`、`Badge` 等共享组件），不直接处理网络请求或状态逻辑，依赖方向单向为 Pages → Hooks → api/client。
