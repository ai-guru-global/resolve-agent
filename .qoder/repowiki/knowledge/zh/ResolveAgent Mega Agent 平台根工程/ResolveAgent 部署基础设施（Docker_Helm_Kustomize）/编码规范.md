- 所有外部配置通过环境变量注入，compose 中使用 `${VAR:-default}` 语法提供默认值，关键密钥（如数据库密码）强制无默认值以阻止误用。
- 每个 compose 服务均声明 `logging.driver=json-file` 并限制 `max-size` 与 `max-file`，避免日志无限增长。
- Dockerfile 采用多阶段构建：builder 阶段编译二进制，runtime 阶段仅拷贝产物并以非 root 用户（resolveagent）运行。
- Compose 服务间通过 `depends_on.condition=service_healthy` 或 `service_started` 显式声明启动依赖，而非隐式顺序。
- Helm values 将 platform/runtime/webui 及依赖组件（postgresql/redis/nats/ingress）拆分为独立命名空间段，便于按需启用或覆盖。
