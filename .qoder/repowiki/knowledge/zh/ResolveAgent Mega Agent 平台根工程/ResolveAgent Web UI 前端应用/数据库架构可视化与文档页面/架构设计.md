模块由两个并列的 React 页面组成：`pages/Database/index.tsx` 作为入口聚合页，通过 `Tabs` 组件将 `SchemaTab`（字段/索引/外键浏览）、`RelationshipTab`（关系图）和 `MockDataTab`（示例数据表格）组合在一起，并在顶部用 `MetricCard` 汇总表、列和外键数量；`pages/DatabaseSchema/index.tsx` 是独立的架构文档页，以可折叠区块形式呈现设计原则、迁移文件清单、按功能分组的表概览、外键列表、ASCII 存储架构图与实体关系图。所有页面的数据源统一来自共享常量文件 `data/dbSchema.ts`，该文件通过 TypeScript 接口（`TableDef`、`ColumnDef`、`ForeignKeyDef`、`IndexDef`）和 `col()` 辅助函数集中声明了全部 16 张表的字段定义、外键约束、索引及 mock 数据，并按迁移编号（001~007）分段组织。依赖方向单向：页面组件 → `dbSchema.ts` 静态数据，不发起网络请求，属于纯前端展示层。
