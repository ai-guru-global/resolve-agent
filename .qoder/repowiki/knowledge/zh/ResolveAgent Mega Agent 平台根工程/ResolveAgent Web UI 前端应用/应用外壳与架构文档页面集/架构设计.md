本模块是 web/src/pages 下的多个独立 React 页面目录，每个子目录仅包含一个 index.tsx 作为路由入口，由上层路由配置挂载到不同 URL。
- 数据驱动型页面：Dashboard/index.tsx 通过 @/hooks/useDashboard 中的多个 useXxx hook（useDashboardMetrics、usePlatformStatus、useAgentOverviews、useActivityEvents、useExecutionStats、useAlerts）拉取实时数据，使用 @/components/ui/*（Card、Tabs、ScrollArea、Skeleton 等）和 @/components/MetricCard、StatusBadge、StatusDot 等共享组件构建仪表盘；其余页面多为纯展示型静态文档页。
- 统一布局约定：所有页面顶部通过 @/components/PageHeader 渲染标题与描述，并通过 react-router-dom 的 Link/useNavigate 在页面间跳转（如 /agents、/playground、/architecture）。
- 依赖方向单向向下：页面只依赖 @/components、@/hooks、@/types、@/lib/utils，不反向引用其他 pages；各 page 之间无相互依赖，完全解耦。
- 技术栈：React + TypeScript + Tailwind CSS + lucide-react 图标 + shadcn/ui 风格组件；Dashboard 还内联 SVG（MiniSparkline）与自定义进度条实现轻量图表。
