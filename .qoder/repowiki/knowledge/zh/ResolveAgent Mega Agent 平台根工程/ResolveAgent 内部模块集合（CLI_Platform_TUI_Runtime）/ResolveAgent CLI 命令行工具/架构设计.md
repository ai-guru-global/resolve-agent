模块以 `root.go` 中的 cobra root command（`resolveagent`）为唯一入口，通过 `Execute()` 暴露给主程序；在 `init()` 中集中注册 `agent`、`skill`、`workflow`、`rag`、`corpus`、`config` 六个业务子命令组以及 `version`、`dashboard`、`serve` 三个独立命令。每个子命令组位于独立子包（如 `internal/cli/agent`、`internal/cli/skill`），由各自的 `NewCmd()` 工厂函数创建并挂载到根命令下，形成扁平的命令树结构。配置统一通过 viper 管理：根命令启动时加载 `$HOME/.resolveagent/config.yaml`，支持 `--config` 覆盖并以 `RESOLVEAGENT_` 前缀自动绑定环境变量。所有子命令的业务实现均依赖同模块内的 `client` 子包——该包封装了 base URL（`http://<server>/api/v1`）、HTTP 方法（Get/Post/Delete）与 JSON 序列化，并为 Agent/Skill/Workflow/RAG/Corpus 各资源定义请求/响应结构体，CLI 命令仅负责解析参数、调用 client 并格式化输出，不直接操作网络或持久化存储。
