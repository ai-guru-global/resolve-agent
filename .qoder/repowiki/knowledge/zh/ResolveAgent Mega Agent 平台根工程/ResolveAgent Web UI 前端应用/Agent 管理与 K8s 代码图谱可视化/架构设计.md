模块按职责划分为三层：
- 页面层 `pages/Agents/`：每个 `.tsx` 对应一个路由视图，围绕单个 Agent 实体组织 UI（AgentList → AgentDetail → ExecutionDetail），并通过 Tabs + Card 组合呈现 Harness、运行状态、执行历史、Memory、Analytics、Diagnostics、Deployment、Collaboration、Templates、AccessControl 等子功能；页面之间通过 react-router-dom 的 Link 跳转。
- 数据层 `hooks/useAgents.ts`：集中封装所有基于 @tanstack/react-query 的自定义 Hook（useAgents、useAgent、useAgentExecutions、useAgentRuntimeStatus、useCreateAgent、useUpdateAgent、useAgentConversations、useConversationMessages、useAgentLongTermMemory、useAgentExecutionDetail、useAgentAnalytics、useAgentDiagnostics、useAgentDeployment、useAgentDeploymentVersions、useAgentLogs、useAgentTemplates、useCollaborationSessions、useAgentAccessRules、useAgentAuditLog），统一以 `['agents', id, ...]` 形式的 queryKey 命名空间隔离缓存，并在 mutation 成功后通过 invalidateQueries 刷新相关列表。
- 可视化组件层 `components/K8sCorpus/`：以 `ChainFlowViewer` 为入口，基于 `@xyflow/react` 渲染 K8s 源码调用拓扑图，内置 sequential-pipeline 与 event-driven 两种布局算法，节点类型 SourceFileNode 与边类型 FunctionCallEdge 拆分展示文件元信息与函数调用关系，RAGCorpusPanel 与 CodeSnippetPanel 提供侧边语料与代码片段查看。
依赖方向单向：页面 → hooks → api/client → 后端；K8sCorpus 组件仅依赖 types/k8sCorpus 类型定义，不反向依赖页面。
