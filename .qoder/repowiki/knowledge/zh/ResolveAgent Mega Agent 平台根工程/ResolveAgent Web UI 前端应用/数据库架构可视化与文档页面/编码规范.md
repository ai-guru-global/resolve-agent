- 表结构通过 `TableDef` 对象 + `col()` 工厂函数声明，统一包含 name/displayName/description/migration/columns/foreignKeys/indexes/mockData 字段，便于多页面复用。
- 每个表对象都附带一组 `mockData` 样例记录，供 `MockDataTab` 直接渲染为表格展示。
- 页面内分组信息（如 `tableGroups`、`migrations`、`designPrinciples`、`foreignKeys`）以顶层常量数组形式定义，再在 JSX 中 `.map()` 渲染，避免硬编码分支逻辑。
- 外键删除策略通过 `onDelete: 'CASCADE' | 'SET NULL'` 字符串区分，并在 UI 上通过 Badge 的颜色变体（destructive/secondary）直观表达。
- 复杂内容区块统一封装为 `ExpandableSection` 组件，通过 `defaultExpanded` 控制默认展开状态，保持页面折叠层次一致。
