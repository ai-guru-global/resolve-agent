- 所有路由实现遵循 `SelectorProtocol` 的结构化协议（实现 `route` 与 `get_strategy_info`），无需显式继承即可被类型检查识别。
- 策略类通过 `IntelligentSelector._get_strategy` 懒加载并按名称缓存实例，避免重复初始化正则与 LLM 客户端。
- 路由决策统一封装为 Pydantic `RouteDecision`，包含 `route_type`、`route_target`、`confidence`、`reasoning`、`parameters`、`chain` 等字段，下游通过属性访问而非字典键。
- 长耗时 I/O（查询 skill/workflow/RAG 注册表、对话历史）使用 `asyncio.gather` 并发拉取，再串行排序与合并。
- 正则表达式在模块初始化阶段预编译为 `re.Pattern` 列表（如 `INTENT_PATTERNS`、`LANGUAGE_PATTERNS`、`ISSUE_PATTERNS`），运行时仅调用 `.search()`。
- 对外部依赖（`IntentAnalyzer`、`ContextEnricher`、策略类、适配器）采用函数内 `import` 的惰性导入方式，避免循环依赖与启动开销。
- 可观测性通过 `logging.info/warning` 配合 `extra={...}` 结构化日志字段记录，审计记录经 `DecisionAuditLogger` 异步队列写入而不阻塞主流程。
