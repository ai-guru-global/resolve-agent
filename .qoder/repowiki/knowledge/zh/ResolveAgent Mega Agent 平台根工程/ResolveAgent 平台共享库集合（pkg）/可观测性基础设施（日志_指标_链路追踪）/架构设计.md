模块按关注点拆分为三个独立子能力，均通过包级全局变量暴露单例：
- `logger.go`：基于 Go 标准库 `log/slog`，通过 `NewLogger(level, format)` 根据 level 映射到 slog.Level，并根据 format 选择 JSON 或 Text Handler 输出到 stdout。
- `metrics.go`：使用 `prometheus/client_golang` + `go.opentelemetry.io/otel/sdk/metric` 构建指标体系；`InitMetrics` 创建 Prometheus Registry、OTEL MeterProvider（ManualReader）、HTTP `/metrics` 端点，并启动 goroutine 周期收集 runtime 指标；定义 request/agent/system 等常用 Counter/Gauge/HistogramVec，并通过 `MetricsMiddleware` 包装 `http.Handler` 自动记录请求数、耗时与活跃连接数。
- `tracer.go`：基于 `go.opentelemetry.io/otel` SDK，`InitTracer` 建立 OTLP gRPC 导出器、设置全局 TracerProvider 与 TraceContext+Baggage 传播器，并通过 `StartSpan`/`AddEvent`/`RecordError`/`MarkSpanError` 等便捷函数操作当前 Span；`HTTPMiddleware` 委托给 `otelhttp.NewHandler` 实现 HTTP 链路追踪。
依赖方向单向：调用方仅依赖本包导出的 `NewLogger`、`InitMetrics`、`InitTracer` 及中间件，不感知底层 OTEL/Prometheus 细节；所有组件返回 shutdown 函数以支持优雅关闭。
