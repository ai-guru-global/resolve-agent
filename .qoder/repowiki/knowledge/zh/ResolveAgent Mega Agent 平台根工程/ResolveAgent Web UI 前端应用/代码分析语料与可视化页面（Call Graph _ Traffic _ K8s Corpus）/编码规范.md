- 每个页面组件采用「列表 + 详情 Dialog」结构：列表页用 Card 网格展示统计摘要，点击后打开 Dialog 加载单条详情，错误/空态统一走 `EmptyState` 组件。
- Mock 数据模块遵循固定模式：定义 seed 数组 → `buildDefaultPayload()` 构造 `{pagination, list, details}` → `getScenarioPayload()` 根据 `resolveMockScenario` 返回不同场景 → 导出 `listXxxMock`/`getXxxMock`/`deleteXxxMock`/`resetXxxMockState`。
- 所有 mock 输入均通过 `shared.ts` 的 `expectRecord`/`expectString`/`expectNumber`/`expectArray`/`expectStringArray` 进行运行时校验，非法数据抛出 `MockValidationError`。
- RAG 文档生成器对每种文档类型封装为独立的 `generateXxxDocs(chain)` 函数，统一产出 `{id, docType, title, content, metadata}` 结构的 `RAGDocument`，并通过 `baseMetadata` 注入链级元信息。
- 页面中通过 `useMemo` 缓存选中的 chain/file 及聚合指标（如 totalFiles、totalFunctions），避免重复计算。
- UI 样式通过 `cn()` 工具组合 Tailwind 类名，并根据 `chain.chainType`（troubleshooting vs 集群初始化）和 `topology`（event-driven vs sequential-pipeline）动态切换配色与文案。
