模块由三个页面组件和一个数据 Hook 组成，围绕 FaultTree 模型组织：
- `WorkflowList.tsx`：通过 `useWorkflows()` 拉取工作流列表，使用 `DataTable` + `StatusBadge` 展示，并提供跳转到设计器和执行页的导航。
- `WorkflowDesigner.tsx`：基于 `@xyflow/react`（ReactFlow）渲染只读故障树，内部 `buildFlowData` 将后端 `FaultTree`（events/gates/top_event_id）经 BFS 计算深度并按列分组布局，映射为 `ftaNode`/`gateNode` 两类自定义节点。
- `WorkflowExecution.tsx`：用 `Tabs` 切换「FTA 树编辑器」和「执行记录」两个视图；前者调用 `FTATreeEditor` 并配合 `useSaveFaultTree` 保存修改，后者汇总成功率、平均耗时等指标并以表格列出执行历史。
- `hooks/useWorkflows.ts`：封装所有数据访问，全部基于 `@tanstack/react-query` 的 `useQuery`/`useMutation`，queryKey 采用 `['workflows', id, 'fault-tree']` 等层级结构，写操作通过 `queryClient.invalidateQueries` 同步缓存。
依赖方向单向：页面 → hooks → `api.client`，UI 组件仅消费类型 `WorkflowDetail`/`WorkflowExecutionRecord`/`FaultTree`，不直接调用 API。
