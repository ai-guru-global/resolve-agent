本模块由两个并列子目录组成，分别承担平台侧配置与运行时技能注册职责：
- configs/：存放 ResolveAgent 各组件的声明式 YAML 配置。`resolveagent.yaml` 定义平台服务（HTTP :8080 / gRPC :9090）、数据库（Postgres）、Redis、NATS、Higress AI Gateway 集成、MCP 外部工具、反馈环与可观测性告警；`runtime.yaml` 定义 Python 侧 Agent Runtime（gRPC :9091）、Agent 池、选择器策略、记忆存储、熔断器与自适应行为；`models.yaml` 是 LLM 模型注册表，按 provider（qwen/wenxin/zhipu/kimi/mimo）声明 model_name、base_url、max_tokens 等参数；`examples/` 提供 agent/skill/workflow 的示例配置片段。
- skills/：以 `registry.yaml` 为唯一入口，列出所有可用技能（含内置 web-search/code-exec/file-ops 与 examples 下的 hello-world/ticket-handler/consulting-qa/k8s-pod-crash），每个技能是一个独立目录，包含 `manifest.yaml`（声明 name/version/description/entry_point/inputs/outputs/permissions/timeout_seconds）和 `skill.py`（暴露 `run()` 函数作为执行入口）。该结构使平台可在运行时按名称动态加载技能并校验其权限与超时约束。
依赖方向单向：平台代码读取这些 YAML 完成初始化，skills 本身不反向引用平台代码，仅通过标准 Python 接口暴露能力。
