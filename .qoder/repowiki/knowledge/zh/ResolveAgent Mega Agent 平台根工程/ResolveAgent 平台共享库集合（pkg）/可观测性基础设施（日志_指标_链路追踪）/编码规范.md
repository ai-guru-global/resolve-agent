- 每个可观测性子系统通过 `InitXxx(cfg, logger) (shutdown func(), error)` 模式初始化，返回 shutdown 函数用于优雅关闭。
- 配置项采用 struct 传入并在内部做空值回退（service name/version 默认值、环境变量兜底、端口路径默认值）。
- Prometheus 指标统一通过 `promauto.With(prometheusRegistry).New*` 注册，并以 `serviceName_` 前缀命名，避免跨服务冲突。
- Span 操作封装为 `StartSpan`/`AddEvent`/`RecordError`/`MarkSpanError` 等便捷函数，内部先检查 `Tracer == nil` 以支持未初始化时的 no-op 行为。
- HTTP 可观测性以 `http.Handler` 中间件形式暴露（`MetricsMiddleware`、`HTTPMiddleware`），便于在路由链中组合。
