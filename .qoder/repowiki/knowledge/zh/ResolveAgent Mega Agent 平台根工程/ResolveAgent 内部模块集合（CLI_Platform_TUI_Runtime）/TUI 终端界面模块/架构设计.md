模块以 bubbletea 的 Model/Update/View 模式组织：`app.go` 中的 `Model` 作为根应用，维护当前视图名（dashboard/agents/workflows/logs）并处理键盘与窗口尺寸消息；各功能按职责拆分为子包——`views/` 下每个文件对应一个视图（DashboardView、AgentListView、AgentDetailView、WorkflowViewer、LogViewer），通过结构体承载数据并提供渲染逻辑；`components/` 提供可复用 UI 原语（Table、StatusBar）；`styles/theme.go` 集中定义颜色、文本样式与边框等主题常量，被 app 和各视图复用。依赖方向单向：app → views → components ← styles，组件与样式不反向引用视图。测试文件（`tui_test.go`、`views_test.go`、`theme_test.go`）与源码同目录或子目录内并列放置。
