模块采用标准 Vite + React 18 + TypeScript 单页应用结构：`src/main.tsx` 通过 `ReactDOM.createRoot` 挂载根组件；`src/App.tsx` 使用 `react-router-dom` 的 `BrowserRouter` 定义 `/`、`/diagnose`、`/skills`、`/history`、`/settings` 五个路由，并内置 `PhoneFrame`（模拟 iPhone 外观、状态栏、Dynamic Island、Home Indicator）和底部固定 `TabBar` 作为全局导航容器；各业务页面以独立文件置于 `src/pages/`（Home、Diagnose、Skills、History、Settings），通过相对路径导入并在 `<Routes>` 中注册。样式体系由 Tailwind CSS 3 驱动，自定义字号（micro/caption/label/title/display）、品牌色（brand、ops）与字体族，并通过 CSS 变量（如 `--color-bg`、`--color-accent`、`--font-display`）在 `index.css` 中集中定义，JSX 中以 `style={{}}` 内联引用以实现暗色主题。Vite 配置 (`vite.config.ts`) 仅启用 `@vitejs/plugin-react`，开发服务器端口为 4000 且 host 开放；构建流程通过 `package.json` scripts 串联 `tsc && vite build`。
