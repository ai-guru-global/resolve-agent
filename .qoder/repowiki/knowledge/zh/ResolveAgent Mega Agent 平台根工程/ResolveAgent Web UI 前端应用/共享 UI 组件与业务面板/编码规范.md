- 原子组件统一通过 `cva` 定义 variants（如 variant、size），并以 `React.forwardRef` + `asChild` + `Slot` 暴露可组合接口。
- className 合并一律使用 `cn(...)` 工具函数，避免字符串拼接冲突。
- 基于 ReactFlow 的组件通过 `nodeTypes` / `edgeTypes` 对象注册自定义节点与边，并使用 `useNodesState` / `useEdgesState` 管理状态。
- 复杂交互（如 FTATreeEditor）采用本地快照式 undo/redo 历史栈，每次变更先 `history.push` 再更新状态。
- 数据模型与可视化之间通过显式的转换函数（如 `faultTreeToFlow`、`flowToFaultTree`）解耦，便于导出/导入。
- 布局组件通过 `react-router-dom` 的 `useNavigate` 进行页面跳转，并将导航项集中声明为配置数组（名称、href、icon、external）。
