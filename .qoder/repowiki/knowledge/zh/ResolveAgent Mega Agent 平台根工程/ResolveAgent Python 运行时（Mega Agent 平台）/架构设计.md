顶层 `resolveagent` 包按职责拆分为多个子模块：`runtime` 提供 FastAPI/uvicorn gRPC 服务与生命周期管理，作为所有外部请求的统一入口；`selector` 作为元路由器根据意图与上下文将请求分发到 `skills`（插件化技能执行）、`code_analysis`（静态分析与错误诊断）、`rag`（检索增强生成）、`fta`（故障树工作流）或 `traffic`（动态流量分析）等子系统；这些子系统通过 `store` 异步 HTTP 客户端访问 Go 平台后端存储，通过 `llm` 多提供商抽象调用大模型，并通过 `hooks` 在关键操作前后注入审计、记忆写入等横切逻辑；`integrations` 将核心能力桥接到 Dify/LangGraph，`mcp` 暴露 MCP 协议工具，`corpus` 与 `docsync` 提供离线语料导入与文档同步 CLI；`top_level_runtime` 提供共享的记忆、消息总线、规划与工具中心供各子模块复用；所有子模块通过 pydantic 模型、OpenTelemetry 追踪与 ruff/mypy 配置保持类型与风格一致。
