模块由两部分组成：`docs/` 存放原始 Markdown 源文档（按 `adr/`、`api/`、`architecture/`、`demo/`、`dev-guide/`、`i18n/`、`ops/`、`papers/`、`rfcs/`、`user-guide/`、`zh/` 等主题目录组织），`docs-site/` 是独立的 Docusaurus 站点工程，通过 `docusaurus.config.ts` 配置默认语言为 `zh`、启用 `zh`/`en` 双语言、设置 GitHub Pages 部署路径 `/resolve-agent/`，并通过 `sidebars.ts` 将文档组织为用户指南、架构设计、开发者指南、API 参考、运维手册、架构决策六大侧边栏分类；站点使用 `@docusaurus/preset-classic` 预设 + `@docusaurus/theme-mermaid` 渲染 Mermaid 图表，自定义页面位于 `src/pages/`，样式在 `src/css/custom.css`，静态资源放在 `static/img/`；`blog/` 目录承载博客文章，`docs/docs/` 下放置站点专属文档（如 ADR 与开发指南）。
