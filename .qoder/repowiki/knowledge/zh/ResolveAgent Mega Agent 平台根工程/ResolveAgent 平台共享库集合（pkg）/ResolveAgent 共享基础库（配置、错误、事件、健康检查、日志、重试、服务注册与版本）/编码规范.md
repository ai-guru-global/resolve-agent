- 公共能力通过函数式 Option 模式暴露可配置项（如 logger.New 的 WithLevel/WithFormat/WithOutput/WithAttrs）。
- 可扩展行为通过小接口解耦（event.Bus、health.FeedbackEmitter、retry.RetryObserver），实现类放在同包其他文件中。
- 错误采用统一结构体 + 常量 Code 枚举，并提供 New/Wrap/Newf/Wrapf 等工厂方法与 HTTPStatus 映射。
- 配置集中管理默认值并通过 viper.SetDefault 声明，环境变量使用前缀 RESOLVEAGENT 并自动映射。
- 健康检查以命名 Check 函数形式注册到 Checker，Run 时聚合各组件状态并检测 UP/DOWN/DEGRADED 转换。
- 重试策略使用 Policy 结构体描述 MaxAttempts/InitialDelay/MaxDelay/Multiplier/Jitter/RetryIf，并通过 DefaultPolicy 提供合理默认。
