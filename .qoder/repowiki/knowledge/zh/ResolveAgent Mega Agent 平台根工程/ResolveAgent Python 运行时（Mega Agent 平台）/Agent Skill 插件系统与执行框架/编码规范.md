- 所有 skill 通过 `manifest.yaml` 声明 `entry_point`（module:func），由 `SkillLoader` 用 `importlib.import_module` 动态加载，默认函数名为 `run`。
- 输入/输出参数统一使用 `SkillParameter` 模型声明 name/type/required/default/enum，并由 `SkillExecutor._validate_inputs/_validate_outputs` 在运行时做类型与枚举校验。
- 沙箱执行采用“临时文件 + 子进程 + `preexec_fn` 设置 `resource.setrlimit`”的模式，Python/JS 代码通过 JSON 注入 inputs 后打印 stdout，再由父进程解析。
- 错误路径统一返回包含 `success=False`、`error`、`duration_ms` 的结构化结果对象（`SkillResult` / `SandboxResult`），而非抛异常上溯。
- 内置 skill 以类封装能力（如 `CodeExecutionSkill`、`WebSearchSkill`），并在模块顶层暴露同名 async 便捷函数供外部直接调用。
- 日志记录统一使用 `logging.getLogger(__name__).info/warning/error(...)` 并通过 `extra={...}` 注入结构化上下文字段（skill_name、step_id、provider 等）。
