- 每个资源域单独一个文件，定义一个继承自 `BaseStoreClient` 的 Client 类并提供 create/get/list/update/delete 等标准 CRUD 方法。
- HTTP 请求全部通过基类的 `_get/_post/_put/_delete` 私有方法发起，禁止在子类中直接使用 `httpx` 或拼接 URL。
- 返回的 JSON 列表通过列表推导式转换为对应的 dataclass 对象，缺失字段使用 `.get(key, default)` 提供安全默认值。
- 404 响应在基类 `_get` 中统一转为 `None`，调用方据此判断资源不存在；其他 HTTPError 记录日志后也返回 `None`。
- 所有 Client 构造函数仅接收 `address` 和 `timeout` 两个参数，并通过 `connect()` 延迟创建底层 `AsyncClient`。
- 对外导出的 Client 集中在 `__init__.py` 的 `__all__` 中声明，未在 `__all__` 中的 Client（如 call_graph、traffic_*、skill）视为内部实现。
