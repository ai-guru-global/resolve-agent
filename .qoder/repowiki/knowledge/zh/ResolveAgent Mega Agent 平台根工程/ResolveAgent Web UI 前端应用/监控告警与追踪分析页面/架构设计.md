模块由三个文件组成，按职责分为页面视图层与数据获取层：
- `web/src/pages/Monitoring/index.tsx` 导出 `MonitorAlerts` 组件，使用 Tabs 组织「告警列表」「系统指标」「Loop Engineering」三个子面板，通过本地 mock 数据（`mockAlerts`、`systemMetrics`、`mockFeedbackSignals`、`mockCircuitBreakers`、`mockAdaptiveWeights`）渲染 MetricCard、StatusBadge、Card 等共享 UI 组件。
- `web/src/pages/Traces/index.tsx` 导出 `TraceAnalysis` 组件，以可折叠卡片形式展示 Trace 记录，支持按状态、路由类型和搜索词进行前端过滤，展开后分 Stage 1/2/3（意图分析、上下文增强、路由决策）三栏呈现决策细节。
- `web/src/hooks/useDashboard.ts` 基于 `@tanstack/react-query` 封装一组查询 Hook（`useDashboardMetrics`、`useTickets`、`usePlatformStatus`、`useAgentOverviews`、`useActivityEvents`、`useExecutionStats`、`useAlerts`），统一通过 `../api/client` 的 `api.*` 方法拉取数据，并以命名化的 queryKey（如 `['dashboard','alerts']`）做缓存键。
依赖方向单向：页面 → 共享 UI 组件（`@/components/*`）→ 类型定义（`@/types`）；Hook 层独立于页面，仅依赖 `api/client`，便于被其他 Dashboard 页面复用。当前两个页面仍使用内联 mock 数据，尚未接入 `useDashboard.ts` 中的真实 API。
