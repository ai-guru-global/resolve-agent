该模块为纯 Bash 脚本集合，按职责单一文件组织：setup-dev.sh 负责校验 Go/Python/Node 依赖并安装 uv、pnpm 及默认配置；generate-proto.sh 基于 buf CLI 调用 tools/buf 下的配置文件生成 api/proto 下的 Protobuf 代码；lint.sh 串联 golangci-lint、ruff（check/format）和 buf lint 完成三语言静态检查；quality-gate.sh 作为 CI/合并前入口，通过 check/warn 函数对 Go（vet/build/lint/test/coverage）、Python（ruff/pytest）和 Web（pnpm lint/test）分阶段执行并以 PASS/FAIL/WARN 汇总退出码；coverage-report.sh 聚合 Go 与 Python 覆盖率并写入 test/fixtures/baseline/coverage-baseline.json 基线快照供趋势追踪。所有脚本均以 `set -euo pipefail` 启动并通过 `git rev-parse --show-toplevel` 定位仓库根目录，对外仅暴露命令行接口，不引入任何运行时依赖。
