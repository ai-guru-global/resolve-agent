模块由两个并列的页面子目录和一个共享 hook 组成：`pages/Skills/` 下的 `SkillList.tsx` 与 `SkillDetail.tsx` 通过 `hooks/useSkills.ts` 暴露的 `useSkills` / `useSkillDetail` React Query hooks 获取技能列表与详情，再借助 `@/api/client` 调用后端；`pages/Solutions/` 下的 `SolutionList.tsx` 与 `SolutionDetail.tsx` 则直接在组件内使用 `api.listSolutions` / `api.getSolution` / `api.searchSolutions` / `api.deleteSolution` 等客户端方法完成 CRUD 与搜索，并通过 `@/types` 中的 `TroubleshootingSolution`、`SolutionExecution` 等类型约束数据结构。页面统一复用 `PageHeader`、`StatusBadge`、`EmptyState`、`Card`、`Badge` 等 UI 原子组件，路由通过 `react-router-dom` 的 `Link` 与 `useParams` 在 `/skills/:name` 与 `/solutions/:id` 之间跳转。依赖方向为：页面 → hooks（仅 Skills 侧）→ react-query → api client → 后端；页面不直接持有业务状态，仅 Skills 列表页用本地 state 管理筛选与选中预览。
