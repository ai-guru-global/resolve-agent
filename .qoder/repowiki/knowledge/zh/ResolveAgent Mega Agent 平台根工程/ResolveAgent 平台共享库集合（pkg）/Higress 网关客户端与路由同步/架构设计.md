模块以三层结构组织：
- `client.go` 定义 `Client`，封装对 Higress Admin API（`/routes`、`/services`、`/health`）的 HTTP 调用，并声明 `HigressRoute`、`RouteUpstream`、`RateLimiter`、`RetryPolicy`、`HigressService` 等数据模型，作为本模块对外唯一的网关访问入口。
- `model_router.go` 基于 `Client` 实现 `ModelRouter`，维护内存中的 `map[string]*ModelRoute`（受 `sync.RWMutex` 保护），提供 `RegisterModel`/`UnregisterModel`/`SyncRoutes`，并通过 `modelToHigressRoute` 将高层 `ModelRoute` 转换为底层 `HigressRoute`，同时内置 qwen/wenxin/zhipu 等提供商的基础路由。
- `route_sync.go` 实现 `RouteSync`，通过注入的 `registry.AgentRegistry` 与 `registry.SkillRegistry` 拉取注册表状态，按固定周期（默认 30s）在后台 goroutine 中执行 `Sync`，把平台静态路由、Agent 动态路由、Skill 动态路由分别 upsert 到 Higress，并提供 `Start`/`Stop` 生命周期控制。
依赖方向单向：`RouteSync` → `ModelRouter` → `Client` → Higress Admin API；模块不直接处理业务请求，仅负责配置下发与状态同步。
