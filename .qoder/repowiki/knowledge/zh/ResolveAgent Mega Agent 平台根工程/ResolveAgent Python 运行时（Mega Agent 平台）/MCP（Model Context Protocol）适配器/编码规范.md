- 每个异步客户端都遵循 connect/close/_call_method 三件套模式，并通过 `_connected` 标志与 `asyncio.Lock` 保证连接状态与并发安全。
- 配置项统一使用 Pydantic BaseModel 定义，并提供 `resolve_*` 方法（如 `resolve_command`、`resolve_url`、`resolve_env`）延迟解析环境变量。
- 工具调用结果统一包装为 `MCPToolResult`（含 success/data/error/tool_name/duration_ms），并在 adapter 层捕获异常后转为结构化错误响应。
- 对可选第三方依赖（如 aiohttp）采用运行时 import 并给出明确的 ImportError 提示，避免在无需该传输时引入硬依赖。
- 日志记录统一通过 `logging.getLogger(__name__)` 获取 logger，并在关键路径（初始化、关闭、超时、错误）输出结构化信息。
