模块以 `engine.py` 中的 `DynamicAnalysisEngine` 为编排入口，按阶段串联三个职责清晰的子组件：`collector.py` 通过适配器模式（`_BaseAdapter` 及 `_OTelAdapter`/`_ProxyLogAdapter`/`_EBPFAdapter`）将 eBPF、代理访问日志、OpenTelemetry span 统一归一化为 `RawRecord`；`graph_builder.py` 基于 `TrafficGraphBuilder` 聚合记录生成 `ServiceNode`/`ServiceEdge` 构成的 `TrafficGraphData`，并提供 `to_xyflow` 与 `to_store_format` 两种序列化视图；`report_generator.py` 的 `ReportGenerator` 先执行规则分析（高错误率、高延迟、复杂依赖等），再可选调用 LLM + RAG 进行增强，最终产出 `AnalysisReport`。各组件之间仅通过数据类契约耦合，外部存储（capture/graph client）通过构造注入的可选客户端异步持久化，异常失败时仅记录 warning 不中断流程。模块对外由 `__init__.py` 统一暴露核心类型。
