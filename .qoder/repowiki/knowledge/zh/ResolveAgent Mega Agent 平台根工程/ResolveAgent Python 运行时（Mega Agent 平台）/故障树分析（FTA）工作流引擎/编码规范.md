- 数据模型统一使用 dataclass + StrEnum 表达（如 `EventType`、`GateType`），字段默认值通过 `field(default_factory=...)` 初始化可变容器。
- 外部依赖（skill_executor、llm_provider、rag_pipeline、fta_client）通过构造函数可选注入，缺失时记录警告并返回安全默认值（True/False）。
- 日志统一通过 `logging.getLogger(__name__)` 输出，并使用 `extra={...}` 携带结构化上下文（如 event_id、tree_id、error）。
- 异步求值器采用策略分发：解析 `type:target` 格式的 evaluator 字符串后路由到 `_evaluate_*` 私有方法，未知类型回退为安全默认值。
- 树遍历与排序统一基于 Kahn 算法实现拓扑序，并在检测到环/不连通时回退到反向顺序以保证鲁棒性。
- 结果缓存键由节点 ID 与上下文哈希组合而成（如 `f"{event.id}:{hash(str(context))}"`），支持按执行上下文隔离缓存命中。
