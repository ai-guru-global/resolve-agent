- 所有跨阶段的数据载体均使用 `dataclass` 定义（`RawRecord`、`ServiceNode`、`ServiceEdge`、`TrafficGraphData`、`AnalysisReport`），并通过 `field(default_factory=...)` 提供可变默认值。
- 新增采集源通过实现 `_BaseAdapter.parse` 并注册到 `_ADAPTERS` 字典扩展，保持开闭原则。
- 对外部可选依赖（capture_client、graph_client、llm_provider、rag_pipeline）采用构造注入并在运行时判空处理，保证无依赖时仍可降级运行。
- 长耗时分析过程以 `async def analyze` 产生 SSE 兼容的事件字典流（包含 capture_started / phase / collection_complete / graph_complete / report_complete / analysis_complete 等固定 type 字段），上层只需 `send_sse(event)`。
- 每个子模块独立维护 `logger = logging.getLogger(__name__)`，关键路径（收集、建图、LLM 失败、持久化失败）均以 `logger.warning`/`logger.info` 记录而非抛错中断。
