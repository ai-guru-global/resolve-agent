模块以「每个领域实体一个文件」的扁平结构组织，每个文件定义一组紧密相关的类型与对应的 `InMemory*Registry` 实现：
- 基础抽象层：`template.go` 通过 Go 泛型 `GenericInMemoryRegistry[T]` + `Keyer[T]` / `Validator[T]` 提供可复用的 CRUD + 分页模板；`memory.go` 提供共享的 `ListOptions`。
- 核心实体注册表：`agent.go`、`skill.go`、`workflow.go`、`hook.go`、`rag.go`、`solution.go` 各自定义 `XxxDefinition`/`XxxCollection` 等数据模型、`XxxRegistry` 接口以及 `InMemoryXxxRegistry` 实现，遵循 Create/Get/List/Update/Delete 统一契约。
- 复合分析型注册表：`code_analysis.go`、`call_graph.go`、`traffic_capture.go`、`traffic_graph.go` 在单一注册表中维护主实体与子实体（Findings/Nodes+Edges/Records），并在 Delete 时执行级联删除。
- 文档型注册表：`fta_document.go`、`rag_document.go` 管理 FTA/RAG 文档集合。
依赖方向单向：各实体注册表仅依赖标准库与同包内的 `ListOptions`，不互相引用，便于独立替换为持久化实现。
