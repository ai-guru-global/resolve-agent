- 每个 Dify 工具以成对的 `.py` 实现与同名 `.yaml` 描述文件存放于 `tools/` 目录，并通过 `manifest.yaml` 统一注册。
- 工具类继承自 `resolveagent.integrations.dify.tools` 中的核心实现，仅覆盖 `_invoke` 方法将返回值转换为 Dify 的消息生成器格式。
- 后端连接凭据优先从 Dify 凭据字典读取，回退到 `RESOLVEAGENT_*` 环境变量，缺失时抛出 `ValueError` 提示用户配置。
- 所有 Python 源文件顶部包含模块级 docstring 说明职责，并使用 `from __future__ import annotations` 与 `TYPE_CHECKING` 避免运行时导入 `dify_plugin`。
