以 `src/main.tsx` 为入口挂载 React Router，由 `stores/app.ts`（Zustand）维护全局状态，`api/client.ts` 封装 HTTP 调用，各业务页面通过 `hooks/` 下的 react-query hooks 消费数据；页面按功能域拆分到 `pages/` 子目录（agents、code_analysis、rag、workflows、monitoring_traces、playground_evaluation、app_shell 等），复用 `components/` 中的 shadcn/ui 原子组件与业务面板（ChatInterface、TrafficGraph、TreeEditor、K8sCorpus），并通过 `types/`、`constants/`、`lib/utils.ts` 提供跨模块类型与工具函数。Mock 数据位于 `api/mock*.ts` 与 `mocks/`，便于在无后端时独立运行。
