- 所有 Go 子包共享根 `go.mod` 中的 module path `github.com/ai-guru-global/resolve-agent`，并通过 `internal/` 限制内部包对外可见性。
- 版本信息通过 `-ldflags` 注入 `pkg/version` 的 `Version`、`Commit`、`BuildDate` 字段，供所有 Go 二进制统一输出。
- API 契约以 `.proto` 文件集中维护于 `api/proto`，并通过 `buf` 校验、`hack/generate-proto.sh` 生成多语言客户端，禁止手写 RPC 存根。
- 配置采用 YAML + Viper 约定，运行时参数通过 `configs/` 下的 YAML 与 `.env` 注入，Python 与 Go 侧遵循同一份 schema。
- 可观测性统一基于 OpenTelemetry，所有服务暴露 Prometheus metrics 并通过 OTLP 上报 trace。
