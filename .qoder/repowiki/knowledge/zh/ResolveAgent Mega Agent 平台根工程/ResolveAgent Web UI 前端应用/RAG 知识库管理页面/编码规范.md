- 数据获取统一通过 `hooks/useRAG.ts` 中的 react-query Hook 完成，页面组件只消费 `data` 与 `isLoading` 字段。
- react-query 的 `queryKey` 采用 `['rag', <资源>, <id?>]` 的层级命名空间模式，便于按功能域隔离缓存。
- 空态与加载态通过 `EmptyState` 组件与 `Skeleton` 占位符分别处理，避免裸数据为空时的布局抖动。
- 文档状态与格式等枚举值通过本地 `Record<string, { label, variant/color }>` 映射表转换为 UI 标签，而非在模板中硬编码分支。
