- 每个业务域在独立 handlers 文件中定义一组 CRUD 处理器函数，并在 `registerHTTPRoutes` 中集中注册到 `/api/v1/<domain>` 路径。
- 通过 `registry.*Registry` 接口抽象后端实现，由 `Server.New` 根据配置在 PostgreSQL 与 InMemory 实现间切换，处理器仅依赖接口。
- HTTP 响应统一通过 `writeJSON`/`writeError` 封装，设置 `Content-Type: application/json` 并返回标准 `{error}` 格式。
- 中间件采用 `func(http.Handler) http.Handler` 函数式风格，通过 `context.WithValue` 注入认证上下文，并由 `GetAuthContext`/`HasRole` 读取。
- 认证失败时记录包含 path/method/error 的结构化警告日志并返回 401，跳过路径通过 `SkipPaths` 前缀匹配白名单。
- Python 运行时错误通过 `mapPythonErrorCode` 集中映射为标准 `errors.Code`，避免在各处理器中分散判断。
