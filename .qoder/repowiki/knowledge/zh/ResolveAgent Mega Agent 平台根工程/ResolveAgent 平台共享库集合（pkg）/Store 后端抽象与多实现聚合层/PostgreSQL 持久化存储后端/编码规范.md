- 每个领域实体独立一个 `*_store.go` 文件，定义 `PostgresXxxRegistry` 结构体并通过 `NewPostgresXxxRegistry(*Store)` 构造函数暴露。
- CRUD 方法统一使用 `r.store.pool.Exec/Query/QueryRow` 直接拼接 SQL，并以 `$1, $2...` 占位符传参，避免字符串拼接注入。
- 查询返回空结果时统一检查 `pgx.ErrNoRows` 并包装为 `"xxx not found"` 错误；更新操作通过 `RowsAffected() == 0` 判断未命中行。
- 分页采用 `LIMIT $1 OFFSET $2` 模式，当 `opts.Limit <= 0` 时回退到默认值（如 100 或 200）。
- 可选字段（如 TargetID、UserID、EmbeddingID）在 Scan 时使用 `*string` 指针接收，再根据是否为 nil 赋值，以正确区分 NULL 与空串。
- 插入/更新前对空字符串字段调用 `nilIfEmpty(...)` 转换为 nil，使 JSONB/TEXT 列能正确写入 NULL。
