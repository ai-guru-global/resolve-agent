模块由三个并列的页面/钩子组成，均位于 web/src 下：
- `pages/Playground/index.tsx` 是主入口，通过 `api.executeAgent` 或动态导入的 `@/api/mock` 的 `mockApi` 执行 Agent 调用，配合本地 `useConversationHistory` hook 将消息持久化到 `localStorage`（key 为 `resolveagent-conversation-history`，最多保留 50 条），并提供按 agentId 过滤的历史侧边栏。
- `pages/Playground/useConversationHistory.ts` 封装了 ConversationRecord 的增删改查，以 updatedAt 降序排序并自动同步到 localStorage。
- `pages/Evaluation/index.tsx` 使用 Tabs 组织“评估数据集”“研究验证”“语料雷达图”三个视图，数据以静态常量（datasets、researchQuestions）内联定义；`CorpusRadarSection.tsx` 用原生 SVG 实现多版本雷达图，内置 CATEGORIES/DIMENSIONS/VERSION_SCORES 三类数据及 polarToCartesian 等几何工具函数，并通过 TooltipProvider + 浮动 div 实现悬停提示。
- `hooks/useCodeAnalysis.ts` 基于 `@tanstack/react-query` 暴露 useCallGraphs / useTrafficCaptures / useTrafficGraphs 等查询与删除 mutation，统一通过 `api.*` 客户端访问后端，并在删除后 invalidate 对应 queryKey 列表。
依赖方向单向：页面 → hooks/api/client → UI 组件库（shadcn/ui），不反向依赖业务逻辑层。
