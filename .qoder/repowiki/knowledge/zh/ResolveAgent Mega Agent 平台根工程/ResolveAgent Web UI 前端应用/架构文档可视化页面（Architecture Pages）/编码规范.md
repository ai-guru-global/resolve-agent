- 每个架构子页面导出一个默认函数组件，统一以 `<div className="space-y-6 animate-slide-up">` 包裹内容，顶部放置带图标的 `<h1>` 标题加一行副标题描述。
- 架构图采用内联 SVG 实现：先定义 `SvgDefs`（箭头 marker、阴影 filter），再用统一的 `COLORS` 常量着色，并通过 `Arrow` / `LayerLabel` 等小型辅助组件重复绘制连线与标签。
- 复杂主题拆分为独立的 SVG 绘图函数（如 `ArchitectureDiagram`、`MemoryHierarchyDiagram`、`HybridPlannerDiagram`、`LoopEngineeringDiagram` 等），在页面中按章节顺序调用渲染。
- 配置与示例信息以 `<pre>` 代码块形式嵌入 Card 中展示 YAML/JSON 片段，便于读者直接复制参考。
- 数据与流程信息优先用 `Card` + `Badge` + `Progress` 组合呈现指标与状态，而非表格或外部图表库。
