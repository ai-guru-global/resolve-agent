模块以 `postgres.go` 中的 `Store` 结构体为核心，封装 `pgx/v5` + `pgxpool` 连接池（默认最大25/最小5连接），并提供 `Exec/Query/QueryRow/Begin/Migrate` 等基础能力；每个业务域（agent、skill、workflow、hook、rag、fta、code_analysis、memory、traffic_capture、call_graph）各自一个 `*_store.go` 文件，实现 `pkg/registry` 中定义的对应 Registry 接口，通过 `NewPostgresXxxRegistry(store)` 工厂函数注入共享 `*Store`。数据库迁移内联在 `Store.Migrate` 中，按版本号顺序执行 DDL（当前至 version 14），并维护 `schema_migrations` 表记录已应用版本；所有表均附带 JSONB 字段与性能索引。测试通过 `RESOLVEAGENT_TEST_DSN` 环境变量连接真实 PostgreSQL 实例，并在 `mustOpenStore` 中统一执行迁移与资源清理。依赖方向单向：各 Store → `Store` → `pgxpool`，不反向依赖上层业务逻辑。
