模块以 `pipeline.RAGPipeline` 为编排入口，按 ingest→index→retrieve→rerank 四阶段串联：`ingest/` 提供 `TextChunker`（固定/句子/标题分块策略）与 `Embedder`（通过 DashScope 兼容 API 调用 BGE/text-embedding 模型）；`index/` 通过 `base.VectorStore` 抽象定义连接、集合 CRUD、插入与搜索接口，并由 `milvus.py`、`qdrant.py` 提供具体后端，`Retriever` 在运行时根据 `vector_backend` 参数懒加载对应 store；`retrieve/reranker.py` 以 CrossEncoder（sentence-transformers）为主、LLM 评分与 Jaccard+词频回退的多级重排策略。顶层 `dual_writer.DualWriteRAGPipeline` 将同一批文档同时写入 `code-analysis`（主）与 `kudig-rag`（最佳努力副）两个集合，并通过可选的 `rag_document_client` 把文档元数据与处理状态持久化到 Go 平台 store。依赖方向单向：pipeline → ingest/index/retrieve，子包之间不反向引用 index 或 retrieve。
