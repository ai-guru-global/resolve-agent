测试按 pytest 约定组织为三层：根目录存放面向外部适配器的单文件测试（test_engine.py、test_http_server.py、test_mcp_adapter.py、test_dify_plugin.py、test_langgraph_integration.py、test_fta_parallel.py、test_feedback_loop.py、test_resilient_selector.py）；`unit/` 子目录针对具体组件（selector、fta_engine/parser、skill_loader/adapter、rag_pipeline、planning、memory、chunker_headings、hook_selector、resilience 等）进行细粒度单元测试；`integration/` 子目录通过组合多个子系统验证端到端流程（audit_logger、corpus_import、lifecycle、mega_reply_pipeline、memory_manager、router）。共享夹具集中在 `conftest.py`，提供 `sample_fault_tree` 等构造好的 FaultTree 对象；`fixtures/sample_fta_tree.yaml` 提供 YAML 格式的故障树样例供解析类测试加载。所有异步测试统一使用 `@pytest.mark.asyncio` 标记，同步测试则直接定义普通方法。
