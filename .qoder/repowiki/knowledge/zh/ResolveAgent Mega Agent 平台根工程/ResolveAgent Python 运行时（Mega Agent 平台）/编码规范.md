- 子模块均位于 src/resolveagent/<domain> 命名空间下，通过 __init__.py 暴露高层入口，内部再按 parsers/engine/client 等职责拆分包
- 对外部系统交互统一通过 store 层的异步 HTTP 客户端封装，避免子模块直接耦合 Go 平台 REST API
- 大模型调用统一经 llm.provider 注册表按名称动态实例化，新增提供商只需实现 Provider 接口并注册
- 数据模型统一使用 Pydantic v2 BaseModel，并在 pyproject 中通过 ruff/mypy 强制类型检查与 lint 规则
- 关键路径通过 hooks 框架在 pre/post 阶段注入审计、记忆写入、缓存等横切逻辑，而非在业务代码中硬编码
