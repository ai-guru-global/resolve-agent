模块由三层组成：
- 页面层 `web/src/pages/CodeAnalysis/`：`index.tsx` 作为入口，使用 `Tabs` 将三个子功能（Call Graphs、Traffic Analysis、K8s 源码语料）组织在同一页面；`CallGraphList.tsx`、`TrafficAnalysis.tsx`、`K8sCorpusAnalysis.tsx` 各自独立渲染卡片列表、详情 Dialog 和指标面板，并通过 `@/hooks/useCodeAnalysis` 中的 React Query hooks 获取数据。
- 数据模拟层 `web/src/mocks/codeAnalysis/`：`callGraphs.ts` 与 `trafficAnalysis.ts` 分别维护独立的 mock payload（list + details），通过 `shared.ts` 提供的 `MockApiError`、`expect*` 校验器、`waitForMockLatency`、`resolveMockScenario` 实现统一的场景切换（default/empty/error/invalid）和状态重置能力；测试文件 `*.test.ts` 基于这些 mock 验证接口契约。
- 知识生成层 `web/src/lib/ragCorpusGenerator.ts`：纯函数式前端生成器，接收 `K8sAnalysisChain` 数据，按 14 种文档类型（7 类 Code Analysis + 7 类 Ops Scenarios）输出 `RAGDocument[]`，用于在浏览器端预览后端 `CallChainRAGGenerator` 会产出的语料。
依赖方向单向：页面 → hooks/API → mock（开发时）或真实后端；RAG 生成器仅依赖类型定义，不耦合 UI。
