- 每个 `.proto` 文件顶部声明 `syntax = "proto3"`、`package resolveagent.v1` 及统一的 `go_package` 选项，确保所有 gRPC 类型归属同一 Go 包。
- 分页采用 `PaginationRequest`（page_size/page_token）与 `PaginationResponse`（next_page_token/total_count）成对约定，所有列表 RPC 均复用该模式。
- 资源实体统一通过嵌入 `ResourceMeta`（id/name/description/labels/annotations/created_at/updated_at/created_by/version）表达通用元数据。
- 枚举值以 `*_UNSPECIFIED = 0` 作为默认占位项，并采用全大写前缀命名（如 `RESOURCE_STATUS_UNSPECIFIED`、`SKILL_SOURCE_TYPE_UNSPECIFIED`）。
- 请求/响应消息成对命名（如 `CreateAgentRequest`/`Agent`、`ListSkillsRequest`/`ListSkillsResponse`），保持 gRPC 方法签名的一致性。
- Skill Manifest 的 JSON Schema 使用 `$defs` 拆分 parameter、permissions、scenario_config 等子结构，并通过 `$ref` 复用，强制 name/version/entry_point 为必填字段。
