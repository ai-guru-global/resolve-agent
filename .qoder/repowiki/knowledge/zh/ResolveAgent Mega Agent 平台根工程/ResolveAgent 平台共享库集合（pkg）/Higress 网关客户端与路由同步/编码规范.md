- 所有对 Higress Admin API 的请求均通过 `Client` 方法发起，并使用 `http.NewRequestWithContext` 传入 context，错误统一用 `fmt.Errorf("...: %w", err)` 包装。
- HTTP 响应统一检查状态码，非 2xx 时调用 `parseError` 读取 body 并返回结构化错误，404 在 GetRoute 中特殊处理为返回 nil。
- 路由名称采用前缀约定：模型路由为 `llm-<modelID>`，提供商路由为 `llm-provider-<provider>`，Agent/Skill 路由分别为 `agent-<id>` / `skill-<name>`。
- 每个 `HigressRoute` 都附带 `labels` map（如 `component`、`provider`、`model`、`agent_id` 等），用于标识路由来源与用途。
- 共享状态（`ModelRouter.routes`、`RouteSync.syncedRoutes`）通过 `sync.RWMutex` 保护，读操作使用 `RLock`，写操作使用 `Lock`。
- 长生命周期组件（`RouteSync`）提供 `Start(ctx)` / `Stop()` 成对的生命周期方法，内部使用 `stopCh` 通道与 `context.Done` 双重退出信号。
