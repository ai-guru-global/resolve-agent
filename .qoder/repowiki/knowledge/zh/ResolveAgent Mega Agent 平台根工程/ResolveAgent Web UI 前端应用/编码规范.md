- 页面按功能域组织在 `pages/<Domain>/` 目录下，每个领域一个文件夹并包含 index 入口文件。
- 数据获取统一通过 `hooks/useXxx.ts` 暴露 react-query hooks，页面组件不直接调用 API。
- UI 组件优先复用 `components/ui/` 中的 shadcn/ui 原子组件，业务面板集中在 `components/<Domain>/`。
- 跨模块共享的类型定义放在 `types/`，常量放在 `constants/index.ts`，通用工具函数放在 `lib/utils.ts`。
- 单元测试与组件测试混放在对应源文件旁的 `.test.ts(x)` 文件中，遵循文件名就近原则。
