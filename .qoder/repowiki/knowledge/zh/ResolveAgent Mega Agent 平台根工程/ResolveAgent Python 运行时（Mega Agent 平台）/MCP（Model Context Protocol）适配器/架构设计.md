模块以 `adapter.py` 中的 `MCPAdapter` 作为对外唯一入口，封装生命周期管理（initialize/shutdown）、工具枚举与执行；内部依赖 `registry.py` 的 `MCPRegistry` 负责按配置创建并维护多个 MCP 客户端连接池、发现工具并路由带 `server.tool` 限定名的调用。`client.py` 定义抽象基类 `MCPClient` 及两个具体实现：`StdioMCPClient`（通过 `asyncio.create_subprocess_exec` 启动子进程并以 JSON-RPC 2.0 行协议通信）和 `HTTPMCPClient`（基于 `aiohttp` 以 POST JSON-RPC 调用远程服务），两者共享 `list_tools`/`call_tool`/`health_check` 等高层方法。`config.py` 使用 Pydantic 模型 `MCPServerConfig`/`MCPConfig` 解析 YAML/JSON 配置文件，支持 `${VAR}` 与 `${VAR:-default}` 环境变量替换，默认搜索路径包括 `mcp_servers.json/yaml` 与 `resolveagent.yaml` 的 `mcp` 节。`types.py` 集中定义 MCP Tool、Resource、Prompt、PromptMessage 以及 JSON-RPC Request/Response/Error 等数据模型。依赖方向单向：adapter → registry → client ← config，types 被所有文件共享，`__init__.py` 仅暴露 `MCPAdapter`、`MCPServerConfig`、`load_mcp_config`、`MCPTool`、`MCPToolResult` 五个符号。
