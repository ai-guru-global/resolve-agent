- 每个视图/组件以独立 Go 包或文件组织，并通过构造函数（如 NewDashboardView、NewTable）返回带默认值的新实例。
- 样式统一通过 lipgloss 的 Style 对象声明为包级变量（Title、Subtitle、StatusHealthy 等），由视图直接 Render 使用。
- 主程序遵循 bubbletea 的 Model 三件套：实现 Init/Update/View 方法，并在 Update 中根据 tea.Msg 类型分派处理。
- 视图间切换通过字符串标识符（"dashboard"、"agents"、"workflows"、"logs"）在根 Model 的 currentView 字段中管理。
