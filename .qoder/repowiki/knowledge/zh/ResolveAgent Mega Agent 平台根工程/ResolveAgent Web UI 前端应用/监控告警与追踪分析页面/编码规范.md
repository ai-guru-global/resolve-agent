- 页面组件默认导出函数式组件并以内联 mock 常量（如 `mockAlerts`、`mockTraces`）作为初始数据源，便于在无后端时直接预览 UI。
- 枚举型字段（告警严重级别、路由类型、状态等）集中定义为顶层 `Record<string, ...>` 映射表（如 `SEVERITY_MAP`、`ROUTE_LABELS`、`STATUS_MAP`），在渲染处通过 key 查找 label/variant。
- 状态值到样式类名的映射统一通过 `cn(...)` 组合 Tailwind 类名，并按 `normal|warning|critical` 或 `success|failed|timeout` 等有限集合选择颜色。
- 时间戳统一通过 `new Date(x).toLocaleString('zh-CN')` / `toLocaleTimeString('zh-CN')` 格式化为中文本地时间显示。
- Hook 层每个查询封装为独立的 `useXxx` 函数，使用语义化 queryKey 数组（如 `['dashboard','alerts']`）并通过 `api.get*` 调用后端接口。
