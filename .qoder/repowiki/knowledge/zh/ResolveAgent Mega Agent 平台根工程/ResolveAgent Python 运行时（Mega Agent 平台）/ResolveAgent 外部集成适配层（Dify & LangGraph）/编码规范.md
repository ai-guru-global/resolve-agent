- 对外暴露的集成入口通过 `__init__.py` 的 `__getattr__` 懒加载具体类，避免在模块导入时强制加载可选依赖（如 langgraph）。
- 工具/节点类采用“主方法 + 私有回退方法”结构：先尝试本地实现（本地 FTA 引擎或解析器），捕获异常后降级到远端 API 或基础文本分析。
- 所有外部调用（HTTP、skill 执行、agent.reply）均包裹 try/except 并以 `logger.warning`/`logger.exception` 记录错误，同时返回结构化结果而非抛出异常。
- LangGraph 相关类型与导入仅在 `TYPE_CHECKING` 块或函数体内按需 import，保持对 `langgraph` 包的可选依赖。
- 状态传递统一以 `dict[str, Any]` 形式在节点间流转，并通过 `output_key` / `input_mapping` 参数化键名，避免硬编码 state 字段。
