模块以 `provider.py` 中的抽象基类 `LLMProvider` 为核心契约，定义 `chat`（同步）与 `chat_stream`（异步迭代器）两个抽象方法，以及 `ChatMessage`/`ChatResponse` 两个 Pydantic 数据模型作为统一请求/响应格式；各厂商实现（`qwen.py`、`wenxin.py`、`zhipu.py`）直接继承该基类并通过 `httpx.AsyncClient` 发起 HTTP 调用。`openai_compat.py` 提供通用的 OpenAI 兼容实现，并派生出 `OllamaProvider`、`VllmProvider` 等子类用于本地或自托管推理服务。`model_config.py` 中的 `ModelConfig` + `ModelRegistry` 构成配置-工厂：通过字符串 provider 标识（qwen/wenxin/zhipu/kimi/mimo/openai-compat）在 `get_provider` 中按需 import 对应 Provider 类并注入 api_key/base_url/default_model，实现运行时解耦。`higress_provider.py` 提供绕过直连、经 Higress 网关统一路由的 `HigressLLMProvider`（含 `HigressEmbeddingProvider`），并通过 `create_llm_provider` / `create_embedding_provider` 根据环境变量 `RESOLVEAGENT_LLM_DIRECT`、`RESOLVEAGENT_GATEWAY_ENABLED` 决定走直连还是网关路径。包入口 `__init__.py` 仅暴露 `LLMProvider`，对外隐藏内部实现细节。依赖方向单向：所有具体 Provider → `provider.py` 抽象层，无反向依赖。
