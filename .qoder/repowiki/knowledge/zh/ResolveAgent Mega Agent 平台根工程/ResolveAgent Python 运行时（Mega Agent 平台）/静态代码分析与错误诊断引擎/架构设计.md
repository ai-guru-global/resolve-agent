模块以 `engine.py` 中的 `StaticAnalysisEngine` 作为顶层编排器，按阶段串联四个子组件：1) `ast_parser.py` 通过 Python 内置 `ast` 解析 Python 源码，并通过 `_parse_generic` 中各语言的正则回退支持 Go/JS/TS/Java；2) `call_graph.py` 的 `CallGraphBuilder` 基于 `ASTParser` 产出的函数/调用索引执行 BFS 遍历，产出 `CallGraphResult`（含 `GraphNode`/`GraphEdge`），并可选通过注入的 `call_graph_client` 持久化到 Go 平台；3) `error_parser.py` 的 `ErrorParser` 用每语言专用正则从日志文本中提取 `ParsedError`+`StackFrame`，支持自动语言探测与去重；4) `solution_generator.py` 的 `SolutionGenerator` 先尝试 RAG 检索上下文，再调用注入的 `llm_provider` 生成 `SolutionDocument`，失败时回退到模板方案。`parsers/` 子包提供面向多语言的抽象接口 `BaseParser`/`ParsedFile` 以及 `ParserFactory`（延迟注册 python/java/go/rust 解析器），但当前主要被 `ASTParser` 内部使用。所有对外 API 通过 `__init__.py` 统一暴露，`analyze()` 方法以异步迭代器形式产生 SSE 兼容事件（`analysis_started`/`phase`/`call_graph_complete`/`errors_parsed`/`solutions_generated`/`analysis_complete`）供上层流式推送。
