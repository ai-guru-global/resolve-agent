- 所有配置以单文件 YAML 形式组织，按功能域拆分（resolveagent.yaml / runtime.yaml / models.yaml），并在关键段落使用注释分隔符标注 Loop Engineering（feedback_loop / circuit_breaker / adaptive）等特性块。
- 敏感凭据不在 YAML 中硬编码，而是留空字段并通过 RESOLVEAGENT_* 环境变量注入。
- 每个技能目录遵循 manifest.yaml + skill.py 的双文件约定：manifest 声明元数据、输入输出契约与权限/超时，skill.py 暴露同名 `run()` 函数作为 entry_point。
- 模型注册采用 id/provider/model_name/base_url/max_tokens/default_temperature 的统一字段命名，便于多供应商 LLM 路由。
- 示例配置集中在各自子目录 examples/ 下，与生产配置分离，便于快速验证而不影响默认部署。
