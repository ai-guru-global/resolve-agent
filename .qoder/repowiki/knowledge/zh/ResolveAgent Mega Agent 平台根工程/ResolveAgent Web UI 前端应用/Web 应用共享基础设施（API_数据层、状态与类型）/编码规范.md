- API 调用统一通过 `api.client.ts` 导出的 `api` 对象进行，禁止页面或 hooks 直接调用 fetch。
- 数据获取 hook 使用 `@tanstack/react-query` 的 `useQuery`/`useMutation`，并以业务域前缀的字符串数组作为 `queryKey`（如 `['agents', id]`）。
- 写操作 mutation 成功后通过 `queryClient.invalidateQueries` 使相关列表查询失效，而非手动更新缓存。
- 大型页面组件在 `App.tsx` 中通过 `React.lazy(() => import(...))` 按需加载，并由外层 `Suspense` 提供 LoadingFallback。
- 全局 UI 状态使用 Zustand store 管理，并通过 `persist` middleware 仅序列化指定字段（如 theme、sidebarExpanded）到 localStorage。
- 领域类型集中在 `types/index.ts` 中以 `interface`/`type` 形式导出，API 层只引用类型而不重复定义数据结构。
