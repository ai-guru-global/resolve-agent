- 每个具体 Provider 均继承 `LLMProvider` 并实现 `async chat` 与 `async chat_stream` 两个方法，保持同步与流式双接口一致。
- 请求参数统一使用 `messages: list[ChatMessage]`、`temperature`、`max_tokens` 及 `**kwargs` 透传扩展字段，构造 payload 时先写入固定键再 `payload.update(kwargs)`。
- HTTP 调用统一通过 `httpx.AsyncClient(timeout=60.0)` 发起，错误分支捕获 `httpx.HTTPStatusError` 并记录 status/response 后抛出 `RuntimeError`。
- 流式响应统一按 SSE 协议处理：逐行读取、跳过空行与 `:` 开头行、识别 `data:` 前缀、遇到 `[DONE]` 终止、解析 JSON 后提取 `choices[0].delta.content`。
- 敏感凭据优先从构造函数参数获取，否则回退到对应环境变量（如 `DASHSCOPE_API_KEY`、`OPENAI_API_KEY`、`HIGRESS_GATEWAY_URL`），缺失时记录 warning。
- 日志使用 `logging.getLogger(__name__)` 并以 `extra={...}` 结构化附带 model、usage、status 等上下文信息。
