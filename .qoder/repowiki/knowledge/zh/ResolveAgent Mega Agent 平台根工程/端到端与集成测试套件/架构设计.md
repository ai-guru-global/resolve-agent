测试套件按测试层级划分为四个子目录：`e2e/` 通过 HTTP 客户端直接调用 `localhost:8080/api/v1` 对真实运行的平台发起请求，验证 Agent 创建/查询/执行/删除的完整生命周期、反馈循环与工作流执行；`integration/` 使用 Go build tag `integration` 编译，仅在与构建时启用 `-tags=integration` 时运行，校验健康端点与 Registry CRUD 的 JSON 契约结构；`fixtures/` 提供 YAML 格式的 Agent、Skill、Workflow 配置样本以及覆盖率基线 `coverage-baseline.json`；`testdata/` 和 `load/` 预留用于未来数据与压测用例。所有测试共享 `skipIfNoServer` 模式——在 `helper_test.go` 中通过探测 `/healthz` 或检查 `SKIP_E2E` 环境变量决定是否跳过，确保在无服务器环境下可安全执行。依赖方向单向：测试 → 平台 HTTP API，不反向引用业务包。
