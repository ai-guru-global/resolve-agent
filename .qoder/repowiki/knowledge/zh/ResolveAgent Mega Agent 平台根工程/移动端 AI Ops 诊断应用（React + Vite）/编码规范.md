- 页面组件统一放在 `src/pages/` 下，每个路由对应一个独立的 `.tsx` 文件，并通过相对路径在 `App.tsx` 中集中引入与注册。
- UI 颜色与排版通过 CSS 自定义属性（`--color-*`、`--font-display`、`--duration-*` 等）集中声明，组件中以 `style={{}}` 内联引用而非直接写死色值。
- 导航与跳转统一通过 `react-router-dom` 的 `useNavigate` hook 配合 `navigate('/path')` 完成，避免硬编码 `<a>` 标签。
- 列表与卡片类 UI 使用 Tailwind 原子类组合布局（flex/grid/rounded-2xl/space-y-*），并辅以 `animate-fade-up`、`active:scale-*` 等过渡动画类实现微交互。
- 静态数据（如最近诊断记录、快捷操作项）以模块级常量数组定义在组件文件顶部，便于后续替换为 API 调用。
