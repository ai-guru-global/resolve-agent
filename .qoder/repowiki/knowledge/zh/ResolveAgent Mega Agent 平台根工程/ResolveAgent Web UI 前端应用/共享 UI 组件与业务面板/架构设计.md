模块按职责划分为四个子目录：
- `ui/`：基于 Radix UI + class-variance-authority + Tailwind 的原子组件（button、dialog、command、select 等），统一通过 `@/lib/utils` 的 `cn` 合并 className，并通过 `asChild` + `@radix-ui/react-slot` 实现可组合渲染。
- `Layout/`：应用级外壳，`MainLayout` 组合 `Sidebar`、`Header` 与 `<main>` 内容区，并通过 `react-router-dom` 的 `useNavigate` 和 `@/stores/app` 的 `commandPaletteOpen` 状态驱动全局命令面板（`CommandDialog`）。
- `TreeEditor/`：以 `FTATreeEditor` 为入口，封装 `@xyflow/react` 的 ReactFlow，内置自定义 undo/redo 历史栈（`Snapshot` 数组）、BFS 自动布局、`faultTreeToFlow` / `flowToFaultTree` 双向转换及 YAML 导出；节点类型拆分为 `FTANode`、`GateNode`，属性编辑由 `NodePropertyPanel` 负责，工具栏由 `EditorToolbar` 提供。
- `TrafficGraph/`：只读流量拓扑视图，`TrafficGraphViewer` 将外部传入的 `XYFlowGraphData` 转为 ReactFlow 的 nodes/edges，并注册 `ServiceNode`、`TrafficEdge` 两类自定义元素。
- `ChatInterface/`：轻量聊天面板 `ChatPanel`，仅维护本地消息列表并通过 `onSend` 回调向上层提交。
依赖方向自下而上：业务面板 → `ui` 原子组件；布局与业务面板均消费 `@/stores/app` 与路由能力，不反向依赖业务逻辑。
