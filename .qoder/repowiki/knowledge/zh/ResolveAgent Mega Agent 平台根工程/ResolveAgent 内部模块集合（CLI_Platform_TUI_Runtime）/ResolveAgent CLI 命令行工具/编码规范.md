- 每个子命令组包提供统一的 `NewCmd() *cobra.Command` 工厂函数，并在其中用 `cmd.AddCommand(newXxxCmd())` 挂载具体子命令。
- 具体子命令采用 `newXxxCmd()` 私有构造函数返回 `*cobra.Command`，并在 `RunE` 闭包内完成参数解析、业务调用与错误返回。
- 所有对后端的访问统一通过 `client.New()` 构造的 `Client` 实例发起，按资源维度组织方法（如 `CreateAgent`、`ListSkills`、`IngestDocument`）。
- API 请求路径以字符串拼接方式组合到 `baseURL`（形如 `/agents`、`/workflows/{id}/execute`），响应体通过 `json.Unmarshal` 反序列化为预定义的结构体。
- HTTP 错误统一在 `Get/Post/Delete` 内部检查状态码 ≥400 并包装为 `fmt.Errorf("API error %d: %s", ...)` 向上抛出。
- 配置读取一律通过 viper，优先使用 `--config` 指定文件，否则回退到 `$HOME/.resolveagent/config.yaml`，并启用 `AutomaticEnv()` 以 `RESOLVEAGENT_` 前缀注入环境变量。
