- 所有持久化数据结构统一使用 Pydantic `BaseModel` 定义，并通过 `model_dump(mode='json')` / `model_validate(raw)` 进行 YAML/JSON 读写。
- 格式解析采用策略模式：定义 `DocumentProcessor` 抽象基类，新增文件类型只需实现 `translate`/`structure_signature`/`extract_text`/`segments` 并由 `get_processor` 注册分发。
- 翻译前使用正则“保护”不可译片段（反引号代码、URL、链接、LaTeX 数学环境等），翻译完成后再还原，避免破坏文档结构。
- 对外部 translator 通过 `subprocess.run` 以 JSON payload 通信，约定返回纯文本或含 `translation` 字段的 JSON，非零退出码统一转为 `SyncError`。
- 同步方向决策基于 sha256 哈希对比上次快照，同时修改走 `conflict` 并写入 review queue，未配置双向同步时目标侧修改仅记录 warning。
- CLI 参数通过 `argparse` 子命令组织，每个子命令对应 `SyncEngine` 的一个顶层方法，返回值直接格式化输出到 stdout。
