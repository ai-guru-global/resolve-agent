- 所有 I/O 与外部服务调用方法均为 `async def`，并通过 `logging.getLogger(__name__).info/debug/error(..., extra={...})` 记录结构化日志。
- 向量后端通过 `abc.ABC` 基类 `VectorStore` 暴露统一接口（connect/disconnect/create_collection/insert/search/delete/get_stats），各实现类仅替换底层 SDK。
- 可插拔组件（chunker、embedder、retriever、reranker）在 `RAGPipeline.__init__` 中实例化并以私有属性注入，便于测试时通过参数覆盖。
- 对可选依赖采用 try/except ImportError 模式（如 sentence-transformers），并在运行时选择最优策略后优雅降级到简单回退。
- 多后端路由集中在单一位置完成：`Retriever._get_store` 根据 `vector_backend` 字符串选择 Milvus/Qdrant，`pipeline._index_chunks` 通过延迟导入按需加载 MilvusStore。
