- Hook handler 统一采用异步签名 `async def handler(ctx: HookContext) -> HookResult`，并通过 `HookRunner.register_handler` 按 `handler_type` 字符串键注册。
- 对可能引入额外依赖的模块（如 `resolveagent.selector.intent`、`memory_client`、`selector_handlers`）使用 `__init__.py` 中的 `__getattr__` 进行按需懒导入，避免启动时强依赖。
- Hook 执行结果通过 `HookResult.modified_data` 向上游上下文合并，pre-hook 合并到 `input_data`、post-hook 合并到 `output_data`，形成链式数据流。
- Hook 执行耗时通过 `time.monotonic()` 计算并写入 `HookResult.duration_ms`，便于观测与性能分析。
- 异常被捕获后记录错误日志并返回 `HookResult(success=False, error=...)`，保证单个 Hook 失败不会中断整个链路。
