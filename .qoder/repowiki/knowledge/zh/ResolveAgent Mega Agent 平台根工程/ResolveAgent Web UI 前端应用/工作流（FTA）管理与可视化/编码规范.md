- 页面通过自定义 hook（useWorkflows、useWorkflowFaultTree、useWorkflowExecutions、useSaveFaultTree）集中管理数据获取与缓存，组件内不直接调用 api 客户端。
- 查询 key 采用分层数组形式（如 `['workflows', id, 'fault-tree']`），写操作成功后显式 invalidate 对应 queryKey 以刷新缓存。
- 状态枚举统一通过本地 `xxxStatusMap: Record<string, { label; variant }>` 映射到 `StatusVariant`，再由 `StatusBadge` 渲染。
- 表格列定义使用 `DataTableColumn<T>` 泛型声明，数值字段以 `font-mono` 显示，时间字段统一用 `new Date().toLocaleString('zh-CN')` 格式化。
- 路由参数通过 `useParams` / `useSearchParams` 读取并提供默认值（如 `id ?? 'wf-001'`），保证无参数时仍可渲染占位内容。
