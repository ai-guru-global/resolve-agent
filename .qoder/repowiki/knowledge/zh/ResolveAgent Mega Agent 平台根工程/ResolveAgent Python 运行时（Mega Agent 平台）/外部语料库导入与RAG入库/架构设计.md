模块以 `importer.py` 中的 `CorpusImporter` 为编排入口，按顺序协调四个阶段：数据获取（`acquisition.py` 通过 git clone 或本地路径校验）、配置加载（`config.py` 的 `CorpusConfig`/`SourceConfig` 基于 YAML profile 决定 chunking 策略与排除规则）、多源导入（`rag_importer.py`、`fta_importer.py`、`skill_importer.py`、`code_analysis_importer.py`）以及进度上报（`progress.py` 的 `ProgressTracker` 统一产生 SSE 风格的 `ProgressEvent`）。各导入器通过依赖注入接收下游客户端（`RAGPipeline`、`FTACorpusImporter` 持有的 fta_client/skill_client/code_analysis_engine/dual_writer），形成单向依赖：编排层 → 具体导入器 → 解析/适配器（`fta_parser.py`、`skill_adapter.py`、`call_chain_rag_generator.py`、`seed_vectorizer.py`）→ 外部 RAG/存储管线。`__init__.py` 仅暴露 `CorpusImporter`、`CorpusImportRequest` 及 call-chain RAG 相关类型作为对外 API。
