- 对外部重型依赖（redis.asyncio、pymilvus、resolveagent.llm）采用函数体内延迟 import，使模块可在无依赖环境下正常导入。
- 可配置的外部客户端（EpisodicMemoryClient、LongTermMemoryClient、CircuitBreaker）统一暴露 connect/close 方法并以 `_connected` 标志位保护空连接时的操作。
- 使用 dataclass 定义领域实体（MemoryEntry、AgentMessage、Plan、ToolSchema 等），并通过 `field(default_factory=...)` 提供可变默认值。
- 通过 `logging.getLogger(__name__)` 记录日志，并在关键路径使用 `extra={...}` 注入结构化上下文（如 message_id、channel、tool、error）。
- 异步资源的生命周期以成对的 start/stop 或 connect/close 显式管理，并由 `asyncio.Lock` 保护并发访问（如 WorkingMemory、MessageBusRegistry）。
- 错误恢复采用降级策略：LLM 解析失败回退到关键词分解、Redis/Milvus 不可用时跳过持久化并记录 warning、熔断器 OPEN 后走 fallback cascade。
