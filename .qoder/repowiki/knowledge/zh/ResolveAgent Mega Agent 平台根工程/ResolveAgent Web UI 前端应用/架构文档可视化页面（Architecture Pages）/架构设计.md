模块以 `index.tsx` 作为入口聚合页，集中渲染 ResolveAgent 整体四层架构图（Interface → Gateway → Platform → Runtime/Data），并定义共享的 SVG 绘图原语（`SvgDefs`、`Arrow`、`LayerLabel`、`COLORS`）供各子图复用；`MemoryArchitecture.tsx`、`PlannerArchitecture.tsx`、`ToolHubArchitecture.tsx` 各自独立导出默认组件，分别聚焦三层记忆、Hybrid Planner（REACTIVE/DELIBERATIVE 双模式）、ToolHub（Schema 注册 + Capability 映射 + 安全策略）。所有页面均通过 `react-router-dom` 的 `/architecture/*` 路由挂载，依赖 `@/components/ui/*`（Card、Badge、Progress、Tabs）和 `lucide-react` 图标，不引入业务状态逻辑，纯静态文档渲染层。
