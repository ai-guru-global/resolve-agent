模块分为两部分：
- `examples/quickstart/`：纯 YAML 配置示例，`agent.yaml` 定义一个 mega 类型 Agent（含模型、system_prompt、skill 与 selector 策略），`workflow.yaml` 定义基于故障树的诊断流程（top_event/gates/events 结构）。
- `integrations/dify/resolveagent-dify/`：基于 `dify-plugin` SDK 的 Dify 插件包。`manifest.yaml` 声明插件元数据并注册 `provider/resolveagent-dify.yaml`；`provider/resolveagent-dify.py` 实现 `ResolveAgentProvider(ToolProvider)`，通过 `RESOLVEAGENT_ENDPOINT` / `RESOLVEAGENT_API_KEY` 环境变量或凭据校验后端连接；`tools/fta_analyzer.py` 与 `tools/code_diagnosis.py` 分别继承自 `resolveagent.integrations.dify.tools` 中的核心工具类，仅重写 `_invoke` 把返回结果包装成 Dify 期望的 `{type: text, text: ...}` 消息生成器。依赖方向单向：Dify 插件 → resolveagent 核心工具 → ResolveAgent 后端服务，插件本身不实现诊断逻辑，只做协议适配与参数透传。
