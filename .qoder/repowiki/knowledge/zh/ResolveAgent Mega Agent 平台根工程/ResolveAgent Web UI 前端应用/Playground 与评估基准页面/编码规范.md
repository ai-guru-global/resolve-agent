- 页面级状态集中在单个 React 组件内，通过 useState/useMemo/useCallback 管理，复杂副作用放在 useEffect 中触发（如自动保存对话、滚动到底部）。
- 对后端数据的读取统一通过 `@/api/client` 的 `api.*` 方法，删除类操作使用 react-query 的 useMutation 并在 onSuccess 中 invalidate 对应 queryKey 列表以保持缓存一致。
- 可复用的持久化逻辑抽取为独立 hook（如 useConversationHistory），对外暴露 save/delete/getByAgent/clearAll 等纯函数式接口，内部自行处理 localStorage 读写与异常兜底。
- 静态展示型数据（评估数据集、研究问题、语料维度、版本分数）以模块级常量数组定义在文件顶部，便于集中维护与扩展。
- 图表类组件采用“数据 + 几何工具函数 + 渲染组件”分层：先定义 polarToCartesian/buildPolygonPoints 等纯函数，再在 RadarChart 中组合生成 SVG 元素。
- 交互反馈通过 Badge/MetricCard 等轻量 UI 组件呈现，并使用 cn() 工具函数组合条件样式类名，保持 Tailwind 样式的声明式风格。
